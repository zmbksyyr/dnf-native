DNF Native 1.0

打开根目录 DNF-Native.exe，程序会检查 resources 资源文件。

创建实例：点击“创建实例”，选择新建或空文件夹。程序自动解压服务端和
MySQL、初始化数据库，完成后自动选中该实例。已有文件夹不会被覆盖。

选择实例：点击“浏览”，选择先前创建的实例文件夹。每个实例拥有自己的
服务端、配置和数据库数据，切换时保留存档。同一时间启动一个实例。

运行：实例创建完成后默认停止。按需修改服务 IP，点击“整体启动”；
通过“整体停止”或关闭窗口正常停服。日志区显示各服务的原生日志。

删除实例：先停止实例，点击“删除实例”并确认。整个实例文件夹及其中
全部内容都会被永久删除；需要保留数据时请先使用备份功能。

资源：mysql.zip 是官方 MySQL 5.7.44 程序及依赖；native.zip 是可直接
浏览目录和文件名的原生服务端资源。两个 host 和 mysql-control.exe
由 GUI 调用。请将整个 resources 目录与 GUI 一同保留。

数据库默认 root 密码为 uu5!^%jg。官方 mysql、mysqladmin、mysqldump
及 mysqld 位于实例的 mysql/bin/，可直接使用。手动修改密码后，需同步
更新该实例的 client.private.cnf，供控制台进行数据库检查与维护。

本轮已验证环境：Windows 10 x64 10.0.19044。保留 19 个服务入口，其中
安全三件套为可选项；其完整业务、Win7/Win11 和客户端完整验收另见项目记录。
