## 失败尝试与保留边界

中间 GUI 的数据库专项曾因失败详情未自动显示而失败，修正后完整复测通过。一次日志专项等待 game 就绪超时并强制清理，最终复测通过；原失败 receipt 保留。

插件复测曾复制已重复运行的中文路径实例，带入旧 PID，原服务拒绝启动。后续改用已停止的主验证实例完成本轮专项；这不证明重复使用任意中文路径实例的生命周期问题已解决。

另一轮插件专项复制了旧 `.init` 日志，将旧就绪标记误计为本轮启动，产生 0.024 秒的错误观察。现将复制来的 game 日志移出本轮日志目录，重新测试；本阶段只采用新日志的 35.021 秒结果。夹具修正与 GUI 一同提交，不引用旧结果作为性能证据。

首次从本地资源创建实例的专项沿用上一阶段构建身份；本次不将该旧结果归入最终 GUI 的新实测。上述为本 GUI 阶段的验证范围；后续建角、进图、结算、冷重启存档重读和缓存性能的新增结果见[真实游戏与缓存记录](13-gameplay-and-cache-performance.md)。客户端图形初始化及定制 jbz69 PVF 缺口仍保留。
